CAPTURE PHOTOGRAPHY WEBSITE
============================

Files:
- index.html
- style.css
- script.js

GitHub Pages:
1. Create a GitHub repository.
2. Upload all three files.
3. Open Settings > Pages.
4. Select Deploy from a branch.
5. Select main / root and save.

The page is intentionally built as plain HTML/CSS/JS, so no build software is required.

NOTE:
The layout, typography, spacing, sections, black/white editorial style and responsive behavior are recreated from the supplied reference image. The reference image does not contain the original source photographs, so the photo areas use high-quality photographic placeholders. Replace the image URLs in index.html with your own photographs for a closer match to the original design.
